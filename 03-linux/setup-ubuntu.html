🐧 Setup: Fundamenty Linuxa

Instalacja Ubuntu Server 26.04 LTS w VirtualBox

🚨 UWAGA PRZED STARTEM: Pobieramy wersję Ubuntu SERVER, a nie Ubuntu Desktop! Prawdziwe serwery nie mają środowiska graficznego (okienek). Będziemy pracować wyłącznie w czarnym oknie terminala. Witamy w świecie profesjonalistów! ISO Ubuntu Server 26.04 LTS (live-server-amd64, ok. 3 GB)

Krok 1: Tworzenie "Żelaza" (VirtualBox)

Czas: 10 min
Cel: Maszynę LINUX_SERVER tworzysz według wspólnej tabeli z Dnia 0 (Etap 2). Zanim ją uruchomisz, sprawdź:
  • Parametry: 2 CPU, 2048 MB RAM (także na laptopie z 8 GB – przy 1024 MB instalator zgłasza „soft lockup”), dysk 25 GB, zaznaczone Skip Unattended Installation.
  • Karta 1: NAT (Internet) + przekierowanie portu 127.0.0.1:2222 ➔ 22 (SSH z Twojego laptopa).
  • Karta 2: Internal Network INF02-LAN, Promiscuous Mode: Allow All. To nasza odizolowana sieć egzaminacyjna!
🚨 Najczęstszy błąd uczniów: Pominięcie włączenia Karty 2. Jeśli tego nie zrobisz, Twój Linux będzie miał Internet, ale nigdy nie połączy się z Windows Serverem w kolejnych tygodniach!

Krok 2: Instalator (Myszka tu nie działa!)

Czas: 15 min
Cel: Przejście przez tekstowy instalator Ubuntu Server.
💡 Złota Rada Trenera (Nawigacja): W instalatorze Ubuntu Server myszka jest martwa. Używaj klawiatury:
👉 Strzałki / TAB - przechodzenie między polami.
👉 Spacja - zaznaczanie opcji (stawianie krzyżyka [X]).
👉 Enter - zatwierdzanie (kliknięcie "Done").
  • Język: Wybierz English (Zawsze instalujemy serwery po angielsku, łatwiej potem szukać błędów w Google!).
  • Klawiatura: Zmień Layout na Polish.
  • Sieć: Niczego nie zmieniaj. Karta enp0s3 (NAT) powinna dostać od VirtualBoxa adres 10.0.2.15. Karta enp0s8 (INF02-LAN) nie będzie miała adresu – to prawidłowe, w naszej sieci nie ma jeszcze DHCP. Jeśli enp0s3 nie ma adresu, Karta 1 nie jest ustawiona na NAT.
  • Dysk: Zostaw Use an entire disk i Set up this disk as an LVM group ➔ Done.
  • Powiększ partycję systemową: Na ekranie podsumowania w sekcji USED DEVICES wybierz ubuntu-lv ➔ Edit ➔ w polu Size wpisz wartość maksymalną (podaną obok jako max) ➔ Save ➔ Done ➔ Continue.
  • Ubuntu Pro: Skip for now.
🚨 Pułapka z dyskiem: Domyślnie instalator przydziela systemowi tylko część dysku. Jeśli pominiesz powiększenie ubuntu-lv, zabraknie miejsca np. w wyzwaniu z Dockerem. Ratunek po instalacji: sudo lvextend -r -l +100%FREE /dev/ubuntu-vg/ubuntu-lv

Krok 3: Konto Egzaminacyjne i SSH

Czas: 5 min
  • Konfiguracja profilu (Profile setup):

    Na egzaminie INF.02 zawsze wymagane jest konkretne konto. Wypełnij formularz następująco:

    • Your name: Administrator
    • Your server's name: serwer-linux
    • Pick a username: administrator (W Linuxie loginy piszemy małymi literami!)
    • Choose a password: ZAQ!2wsx
  • OpenSSH (Bardzo ważne!):

    Na ekranie "SSH Setup" koniecznie wciśnij Spację przy [X] Install OpenSSH server. Opcję Allow password authentication over SSH zostaw zaznaczoną. Ekran z dodatkami (Featured Server Snaps) pomiń – niczego nie zaznaczaj.

🕵️‍♂️ Sekret Inżyniera: Po co nam to SSH?

Okno VirtualBoxa jest niewygodne. Nie da się w nim łatwo przewijać tekstu do góry, a co gorsza – nie działa kopiuj-wklej z Twojego laptopa!

Instalując OpenSSH, pozwalamy Windowsowi połączyć się z Linuxem. Dzięki przekierowaniu portu z Dnia 0 otworzysz Wiersz poleceń (CMD) na swoim laptopie, wpiszesz ssh -p 2222 administrator@127.0.0.1 i będziesz pracować na serwerze w wygodnym oknie, gdzie działa wklejanie komend! Później, gdy Linux dostanie adres w sieci INF02-LAN, połączysz się też z maszyny klienta: ssh administrator@192.168.10.20. Tak właśnie pracują prawdziwi SysOpsi.

✅ Weryfikacja: Czy system żyje?

Po zakończeniu instalacji i restarcie maszyny, zobaczysz czarny ekran z napisem serwer-linux login:.

  1. Wpisz login: administrator i wciśnij Enter.
  2. Wpisz hasło: ZAQ!2wsx.
    UWAGA: Podczas wpisywania hasła w Linuxie nie pojawiają się gwiazdki (***)! Pisz w ciemno i wciśnij Enter.
  3. Wpisz ip -br a: enp0s3 ma adres 10.0.2.15, a enp0s8 jest UP bez adresu (adres 192.168.10.20 nadasz w Lab 4).
  4. Wpisz ping -c 3 ubuntu.com – 3 odpowiedzi oznaczają, że działa Internet i DNS.
  5. Otwórz CMD na swoim laptopie i wpisz ssh -p 2222 administrator@127.0.0.1 (na pytanie o klucz odpowiedz yes). Jeśli widzisz administrator@serwer-linux:~$ – gratulacje, zbudowałeś swój pierwszy serwer!
  6. Wyłącz maszynę (sudo poweroff) i zrób migawkę 00-czysta-instalacja – Dzień 0, Etap 5.
