🌟 Wyzwanie 3: Konkurencja dla IIS

Błyskawiczny serwer WWW (Nginx) i analiza logów dostępu w czasie rzeczywistym

Cel Wyzwania: Postawienie serwera WWW na Linuxie i porównanie tego procesu z instalacją IIS na Windows Serverze. Zrozumienie, dlaczego większość internetu działa na systemach uniksowych.

Krok 1: Błyskawiczna Instalacja (Nginx)

Czas: 5 min

Przypomnij sobie, jak instalowałeś rolę Serwer sieci Web (IIS) na Windowsie. Menedżer serwera, kreator, wybieranie ról, czekanie na pasek postępu... W Linuxie zrobimy to jednym poleceniem. Użyjemy serwera Nginx (czyt. Engine-X) – najpopularniejszego serwera WWW na świecie.

# 1. Zaktualizuj listę pakietów i zainstaluj Nginx (flaga -y automatycznie potwierdza instalację) sudo apt update sudo apt install nginx -y # 2. Sprawdź, czy usługa działa (powinna wstać automatycznie!) sudo systemctl status nginx

(Wciśnij 'q', aby wyjść ze statusu).

Krok 2: Własna strona WWW

Czas: 10 min

W Windowsie domyślnym folderem dla stron WWW jest C:\inetpub\wwwroot (lub C:\www, jeśli tak ustawisz). W Linuxie standardowym miejscem na pliki stron internetowych jest katalog /var/www/html.

# 1. Przejdź do katalogu ze stroną cd /var/www/html # 2. Zobacz, co tam jest (znajdziesz domyślny plik index.nginx-debian.html) ls -l # 3. Nadpiszmy domyślną stronę własnym kodem HTML (wymaga sudo!) sudo sh -c 'echo "<h1>Witaj z Linuxa! Nginx dziala blyskawicznie!</h1>" > index.html'

Krok 3: Test z Windowsa (i pułapka!)

Czas: 10 min

Przejdź na maszynę Windows 11, otwórz przeglądarkę internetową i wpisz adres IP swojego Linuxa: http://192.168.10.20.

🚨 Strona się nie ładuje? (Jeśli robiłeś Wyzwanie 2) Jeśli w poprzednim wyzwaniu włączyłeś zaporę UFW (sudo ufw enable), to domyślnie blokuje ona cały ruch z wyjątkiem SSH! Musisz wrócić na Linuxa i zrobić "dziurę" w zaporze dla ruchu HTTP (port 80).

Rozwiązanie na Linuxie:
sudo ufw allow 80/tcp
sudo ufw status

Po odblokowaniu portu 80, odśwież stronę na Windowsie. Powinieneś zobaczyć swój wielki napis: Witaj z Linuxa!

Krok 4: Podglądanie ruchu (Access Logs)

Czas: 10 min

Jako administrator musisz wiedzieć, kto i kiedy odwiedza Twoją stronę. Nginx zapisuje każde zapytanie w specjalnym pliku logów. Użyjemy komendy tail -f (poznanej w Labie 6), aby obserwować ten ruch na żywo.

  • Na Linuxie: Uruchom śledzenie logów dostępu:
    sudo tail -f /var/log/nginx/access.log
  • Na Windowsie: Ułóż okna tak, aby widzieć terminal Linuxa. W przeglądarce na Windowsie wciśnij F5 (Odśwież) kilka razy.
  • Obserwuj Linuxa: Zobaczysz, jak z każdym odświeżeniem strony na czarnym ekranie pojawia się nowa linijka! Będzie tam adres IP Twojego Windowsa (192.168.10.30), data, godzina oraz informacja o przeglądarce (User-Agent).

🕵️‍♂️ Sekret Inżyniera: Nginx vs IIS

Dlaczego Nginx jest tak popularny? Ponieważ jest niesamowicie lekki i potrafi obsłużyć dziesiątki tysięcy jednoczesnych połączeń przy minimalnym zużyciu RAMu. W nowoczesnym IT Nginx rzadko serwuje same pliki HTML – najczęściej działa jako Reverse Proxy (odwrotne proxy) lub Load Balancer, rozdzielając ruch na dziesiątki innych serwerów ukrytych na zapleczu.
